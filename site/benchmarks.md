# 量化数据（R0-3 基准，部分已实测）

本页只登记**指标口径与测法**，不登记未实测的数字。

所有指标一律采用**「对比优化前后」的收益类表述**——即「优化前基线 vs 优化后，某项收益 ±X%」。
只报绝对值说服力弱，报**收益差**才能体现「做了优化并且量出来了」。

## 测法说明

| # | 指标 | 测法 |
|---|---|---|
| 1 | API 调用成本 | 同一组问题各跑一遍，比对 `audit_log` 的 input token 与估算成本 |
| 2 | 检索准确率 | 10 条标注集逐条判命中，算命中率差 |
| 3 | 任务等待时间 | 同一多任务目标的墙钟耗时对比 |
| 4 | 首 token 等待时间 | SSE 首 token 延迟（TTFT）中位数 + 流式稳定性，分 provider 记录 |
| 5 | 历史 token 占用 | 与 v0.21.0 共用一套采集口径，关键事实召回不降为前提 |

## 标注集约定

所有基准的「标准答案」一律取自 **AgentCLI 自身源码**（不依赖外部数据集），保证可当场 `git clone` 后一键复跑。

检索准确率标注集固定为 **10 条「问题 → 期望命中文件」**，示例：

| 问题 | 期望命中文件 |
|---|---|
| ReAct 循环在哪 | `ReActAgent.java` |
| MCP 客户端实现在哪 | `mcp/client/*` |
| SSRF 围栏逻辑在哪 | `web/NetworkPolicy.java` |
| 审计装饰器在哪 | `audit/AuditLog.java` |

基准脚本与结果 md 落在仓库 `bench/` 目录，随代码一并提交。

> 已实测数据见仓库 `bench/result.md`，任何人 `git clone` 后执行 `mvn -q test -Dtest=RagBenchTest -DskipTests=false` 可一键复跑；`rag_search` 列需配置 embedding key 后补齐。
